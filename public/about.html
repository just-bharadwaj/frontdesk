What the project does

  • Guides a patient through identity verification and confirmed appointment booking.
  • Supports rescheduling, cancellation, and refill requests.
  • Flags recognized emergency language and clinical questions for human attention.
  • Shows conversations, appointments, review queues, and ordered tool calls.
Explore the working demo

What it demonstrates

  • A responsive customer-facing React and TypeScript application.
  • A connected local FastAPI backend with Pydantic validation.
  • SQLite mock EHR resources and safeguards against slot conflicts.
  • 40 Python checks and 8 browser-engine checks, with CI workflows.

View current CI results

How it works

Public demo: React UI → browser workflow engine → localStorage Local API: React UI → FastAPI → validated tool router → SQLite mock EHR ↳ safety checks + ordered audit trail

GitHub Pages hosts the browser simulation and this video. The optional Python backend runs locally. The project does not currently call a live language model or connect to a phone number.

What can be improved

  1. Connect a live model: add structured tool calling while keeping identity, confirmation, and database permissions on the server.
  2. Add voice and a phone number: connect Twilio and a realtime voice model, handle interruptions, and test safe transfer/fallback behavior.
  3. Deploy shared backend storage: host the Python API and a durable database; persist conversations and audit events.
  4. Add staff authentication: protect records with role-based access and secure session management.
  5. Expand testing: add browser end-to-end tests, realistic language variations, accessibility checks, and backend/frontend parity tests.
  6. Integrate a real sandbox: replace synthetic EHR resources with an authenticated vendor sandbox before considering any real clinical use.

This is a demonstration, not a clinical system or HIPAA-compliant service. Refill requests are never prescription approvals. Staff handoffs are demo records, not live notifications. Use synthetic information only.
